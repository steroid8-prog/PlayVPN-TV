PlayVPN TV — отдельная телевизионная версия PlayVPN. Горизонтальный интерфейс, крупная кнопка подключения и панель серверов позволяют управлять VPN прямо с дивана.


## Возможности


- Навигация стрелками пульта: **OK** — выбрать, **Назад** — вернуться.
- Выбор конкретных серверов подписки в тёмной стеклянной панели.
- Проверка пинга и обновление подписки с пульта.
- Состояние соединения и таймер VPN-сеанса на главном экране.
- Открытие сайта активной URL-подписки в браузере телевизора.
- QR-сопряжение с PlayVPN на телефоне и передача URL-подписки в одной локальной сети.
- Отдельный канал обновлений TV: проверка при открытии приложения и ручная проверка в разделе «О приложении и обновления».


> Для подключения нужна собственная совместимая подписка или конфигурация. Готовый VPN-доступ и персональные ключи в APK не включены. Автоматическое подключение при открытии приложения отключено.


## VPN-подписка и бесплатный пробный период

**Каждый желающий может бесплатно попробовать VPN-подписку в течение пробного периода.** Получить пробный доступ или купить подписку можно в Telegram-боте **[@vpngambot](https://t.me/vpngambot)**.

## Скачать и установить


1. Откройте **[последний выпуск](https://github.com/steroid8-prog/PlayVPN-TV/releases/latest)** и скачайте `PLAY-VPN-TV-1.0.15.apk` из раздела **Assets**.
2. Перенесите APK на телевизор по локальной сети или через USB-накопитель.
3. Откройте файл через файловый менеджер. Если Android запросит разрешение установки из этого источника, разрешите установку для выбранного менеджера.
4. Запустите PlayVPN TV и добавьте свою конфигурацию. Для сопряжения с телефоном откройте **+ TV**, разрешите удалённое управление и отсканируйте QR внутри мобильного PlayVPN. Устройства должны находиться в одной локальной сети.
5. Выберите сервер, нажмите подключение и подтвердите системный запрос VPN.


Устанавливайте обновления поверх предыдущей версии PlayVPN TV, чтобы сохранить настройки. При встроенном обновлении Android может запросить отдельное разрешение установки для PlayVPN TV; финальную установку подтверждает пользователь.

| Параметр | Значение |
| :--- | :--- |
| Устройства | Android TV / Google TV на ARM |
| Минимальная система по APK | Android 5.0 (minSdk 21) |
| Архитектуры | ARM32 (`armeabi-v7a`) и ARM64 (`arm64-v8a`) |
| Версия | **1.0.15** |
| Код версии | `10201056` |
| Пакет | `com.playvpn.android.tv` |


Сборка проверена на двух телевизорах владельца проекта, включая Smart TV Pro на Android 11 с ARM32. Совместимость со всеми моделями и прошивками отдельно не подтверждена. Для телефона используйте **[PlayVPN](https://github.com/steroid8-prog/PlayVPN)**.


## Что изменилось в 1.0.15


- Кнопка подключения опущена ниже заголовка.
- Панель серверов использует пространство между выбором сервера и нижней навигацией.
- Кнопка проверки обновлений доступна с пульта и выделяется светлой рамкой.
- При открытии приложения проверяется новая версия; при наличии обновления появляется напоминание.
